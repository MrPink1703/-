Бинарная куча 


Преобразует произвольный список в кучу (min-heap) за O(n), чтобы далее выполнять быстрые операции извлечения минимума и вставки.

Код

import heapq
a = [8, 3, 5, 1, 6]
heapq.heapify(a)
print(a[0])  # минимум
```

1) Создаём список `a` с данными.
2) `heapq.heapify(a)` перестраивает массив на месте по свойству кучи: каждый родитель ≤ своих детей.
3) После этого `a[0]` — минимальный элемент (корень).
