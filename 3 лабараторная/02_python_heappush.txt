
Добавление элемента в min-heap с сохранением порядка кучи.

import heapq
a = []
heapq.heappush(a, 5)  # куча: [5]
heapq.heappush(a, 2)  # минимум теперь 2
heapq.heappush(a, 7)  # добавили 7
print(a[0])           # 2
```


• Пустая куча `a` — обычный список.
• `heappush(a, x)` добавляет x в конец и «просеивает вверх», пока родитель ≤ ребёнок.
• Корнем остаётся минимальный элемент.
