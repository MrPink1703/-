
Вставить элемент в кучу, размещённую в std::vector (диапазон [begin,end)).


#include <vector>
#include <algorithm>
#include <iostream>
int main(){
    std::vector<int> a;
    a.push_back(5); std::push_heap(a.begin(), a.end());
    a.push_back(2); std::push_heap(a.begin(), a.end());
    a.push_back(7); std::push_heap(a.begin(), a.end());
    std::cout << a.front(); // максимум (7)
}
```


• `push_back` кладёт элемент в конец диапазона.
• `std::push_heap` «просеивает вверх» последний элемент, поддерживая max-heap.
• Корень кучи — `a.front()`.
