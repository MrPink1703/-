
Вернуть и удалить минимальный элемент из кучи.


import heapq
a = [5, 9, 4, 12]
heapq.heapify(a)      # делаем кучу
m = heapq.heappop(a)  # извлекаем минимум
print(m, a[0])
```

• `heappop` меняет местами корень с последним элементом, удаляет хвост,
  затем «просеивает вниз» новый корень, восстанавливая свойство кучи.
